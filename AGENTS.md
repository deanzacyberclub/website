# Agent Guidelines

This is the website for the De Anza ML and Agentic Cybersecurity Club
(React 19 + TypeScript + Vite + Tailwind CSS 4, Supabase backend, deployed on
Netlify).

- Follow the conventions in `DESIGN_SYSTEM.md` (terminal/CLI aesthetic,
  monospace type, no emoji in UI).
- Run `bun run build` before committing to catch type errors.
- Do not commit secrets; environment variables are documented in
  `.env.example`.
