# De Anza ML and Agentic Cybersecurity Club

**[dacc.club ↗](https://dacc.club/)**

A student-led community at De Anza College for learning how modern machine
learning works, building cybersecurity foundations, and getting hands-on with
industry tools like Burp Suite, Nmap, and Wireshark.

## Club Mission

- Learn the basics of machine learning and understand how the models you use
  every day actually work.
- Build cybersecurity foundations that make you a better programmer,
  regardless of specialization.
- Get hands-on with professional penetration-testing tools on legal targets.

No prior experience required — only a willingness to learn and grow.

## Tech Stack

- [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/), built with [Vite](https://vite.dev/)
- [Tailwind CSS 4](https://tailwindcss.com/) for styling
- [Supabase](https://supabase.com/) for auth, database, and edge functions
- Deployed on [Netlify](https://www.netlify.com/)

## Local Development

```bash
bun install        # or: npm install
cp .env.example .env   # fill in Supabase credentials
bun run dev        # or: npm run dev
```
